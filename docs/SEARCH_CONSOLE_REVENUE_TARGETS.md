# Search Console Revenue Targets

This file captures the first landing pages worth monitoring closely in Search Console after the revenue-growth rollout.

## First-Wave Priority Pages

1. `/student-accommodation/best-london-student-areas/`
   Target query themes:
   - `best areas to live in london for students`
   - `best london student areas`
   - `where should students live in london`

2. `/student-accommodation/ucl-student-accommodation/`
   Target query themes:
   - `where to live near ucl`
   - `ucl student accommodation`
   - `best areas to live near ucl`

3. `/student-accommodation/imperial-student-accommodation/`
   Target query themes:
   - `where to live near imperial college london`
   - `imperial college accommodation`
   - `best areas near south kensington for students`

4. `/student-accommodation/lse-student-accommodation/`
   Target query themes:
   - `where to live near lse`
   - `lse student accommodation`
   - `best areas near holborn for students`

## What To Watch First

- Impressions rising before clicks is acceptable in the first phase.
- Compare CTR between the generic student page and the university-specific pages.
- Watch for query drift into low-intent travel searches. If that happens, tighten titles and opening copy further.

## Quick Review Cadence

1. Check Search Console after indexation and after any title or description change.
2. Compare the first-wave pages against each other every 7 to 14 days.
3. If one university page starts outperforming, use that copy pattern on the next wave.

## Why These Pages First

- They align most closely with existing affiliate inventory.
- They have the strongest chance of matching high-intent housing searches.
- They are already featured in the on-site launchpads, so internal linking support is strongest.
